ZORK I

The Great Underground Empire - Modern Web Edition

Experience the classic 1983 text adventure game reimagined for the modern web! This proof-of-concept features a graphical user interface, visual compass navigation, and support for scene imagery while preserving the authentic text adventure gameplay.

Features

  • Retro/modern hybrid interface with classic terminal aesthetics
  • Interactive compass rose for easy navigation
  • Scene display area ready for custom artwork
  • Full text parser supporting natural language commands
  • Real-time inventory management
  • Authentic game content extracted from original 1983 ZIL source code
  • Playable demo with 9 interconnected rooms
